# ETV otse

Kodi plugin ETV, ETV2 ja ETV+ otseülekande jaoks. Voog tuleb ERR-i lehelt [otse.err.ee](https://otse.err.ee/k/etv).

## Paigaldus

1. Kodi seadetes lülita sisse **Seaded → Süsteem → Lisad → Tundmatud allikad**.
2. Lisa failiallikas aadressiga `https://mikklaos.github.io/etv-kodi/`.
3. **Lisad → Paigalda zip-failist** ja vali **Paigalda-ETV-otse.zip**.
4. Kui Kodi küsib, paigalda ka **InputStream Adaptive** (Kodi ametlikust hoidlast).

Otsefail: [Paigalda-ETV-otse.zip](https://github.com/mikklaos/etv-kodi/raw/master/Paigalda-ETV-otse.zip).

Hilisemate uuenduste jaoks võib samamoodi paigaldada [Paigalda-ETV-hoidla.zip](https://github.com/mikklaos/etv-kodi/raw/master/Paigalda-ETV-hoidla.zip) ja seejärel võtta videoplugina hoidlast **ETV Kodi**.

Pildi kvaliteedi saab valida plugina seadetes. Vaikimisi on 1080p.

Osa saateid on ainult Eestis või DRM-iga. Siis see plugin neid ei mängi.
