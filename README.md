# ETV otse

Kodi plugin ETV, ETV2 ja ETV+ otseülekande jaoks. Voog tuleb ERR-i lehelt [otse.err.ee](https://otse.err.ee/k/etv).

## Paigaldus

1. Kodi seadetes lülita sisse **Lisad → Tundmatud allikad**.
2. Laadi alla [repository.etvkodi-1.0.0.zip](https://github.com/mikklaos/etv-kodi/raw/master/zips/repository.etvkodi/repository.etvkodi-1.0.0.zip).
3. Kodi: **Lisad → Paigalda zip-failist** ja vali see zip.
4. **Paigalda hoidlast → ETV Kodi → Videolisad → ETV otse**.
5. Kui Kodi küsib, paigalda ka **InputStream Adaptive** (Kodi ametlikust hoidlast).

Pildi kvaliteedi saab valida plugina seadetes. Vaikimisi on 1080p.

Osa saateid on ainult Eestis või DRM-iga. Siis see plugin neid ei mängi.
